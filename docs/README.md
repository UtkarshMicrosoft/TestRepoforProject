# Documentation

| Folder | What goes here | Requirement |
|---|---|---|
| [`adr/`](adr/) | Architecture Decision Records. At least six: frontend framework, API style, database, authentication, caching, hosting/deployment. Every participant authors at least one. | ARC-07 |
| [`architecture/`](architecture/) | C4 diagrams, deployment diagram, data model (ERD) and data dictionary, Scenario A sequence diagram. Diagrams as code (Mermaid). | ARC-06, DB-C02 |
| [`specs/`](specs/) | A short spec before each major feature. Every participant authors at least two. | AI-03 |
| [`operations/`](operations/) | Runbook, backup and restore drill reports. | OPS-C09, DB-C08 |
| [`ai-journal/`](ai-journal/) | One AI Engineering Journal per participant: at least one entry per week and ten in total. | AI-04 |
